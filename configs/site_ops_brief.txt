SEO HEALTH

- Broken internal + outbound links (quarterly crawl)
- Meta title + description completeness per page
- Sitemap.xml freshness vs /wp-admin content

PRIVACY & COMPLIANCE
- Cookie consent (UK GDPR) — working banner, no pre-ticked boxes
- Privacy policy link in footer of every site
- Contact forms → consent checkbox on submission
- Data retention statement present
- No third-party trackers that aren't declared in the cookie banner

SECURITY
- HTTPS + HSTS header present on every domain
- WP hardening: xmlrpc.php disabled, /wp-login.php not exposed on known paths
- File permissions 644/755
- No world-writable uploads directory
- Two-factor on every admin account (audit quarterly)

PERFORMANCE

- Caching layer (Redis / object cache) confirmed active
- Critical CSS inlined above the fold
